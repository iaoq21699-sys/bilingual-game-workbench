# 接入一款游戏

先选定 **Windows x64 下的具体游戏版本**，并准备一个能重复到达的测试场景。备份存档，记下原来的游戏语言和启动方式。先试一条双语文字，再试面板打开、搜索和返回游戏。

## 1. 接入双语显示

在工作台选「游戏 → 接入新游戏」，选择游戏根目录。确认实际窗口程序、显示语言、中英顺序和排版。退出游戏后完成接入，在游戏里选择向导指定的语言。用普通启动入口或工作台启动均可验证已安装的语言资源。

- **Unreal** 可识别工作台支持的可读 `.pak` / `.locres`，部分 IoStore 版本有对应容器生成路径。压缩组件取决于游戏。若提示需要 Oodle，请按提示提供自己有权使用的本机 `tools/oo2core_9_win64.dll`。
- **Godot** 可从受支持的独立 PCK 读取成对语言 JSON，显示依赖该游戏可用的模组或覆盖包入口。
- **松散 JSON** 需要游戏确实读取成对的语言 JSON。工作台备份目标语言文件后才启用双语。
- **获取模板** 可在「资料 → 从接入配置文件导入」选择 `examples/Expedition33.bilingual.json` 或 `examples/SlayTheSpire2.bilingual.json`，再指定匹配版本的本机游戏目录。导入配置后仍需用游戏画面确认加载与字体。

### 识别失败时

诊断窗口会区分目录不对、接入配置有问题、资源不可配对和缺少适配条件。可在同一个窗口重选目录、导入匹配版本的配置，或走「仅导入文本」。诊断不写游戏文件。「仅导入文本」提供桌面检索、收藏与复习，不会安装 F8 面板或改变游戏原有文字。

## 2. 安装 DirectX 游戏内面板

1. 打开解压目录的 `prepare-native-panel.cmd`。脚本从 [ReShade 官网](https://reshade.me/) 获取与面板匹配的 **6.8.0 Full Add-on**，校验后只提取运行库到工作台 `tools/reshade-runtime`。也可手工从原版安装文件提取 `ReShade64.dll` 放到同一目录。
2. 完全退出游戏。选中该游戏，点「面板设置」。预检会显示实际 EXE、位数、可识别的图形接口、语料数量和已有文件。
3. 预检就绪后点「保存并安装」。启动游戏，**F8** 打开。看到「面板已加载」后，亲自输入关键词，点词并按 **Esc**，确认游戏重新接收输入。
4. 测一次「固定阅读」。小卡应避开字幕和小地图，并允许游戏继续操作。需要停住画面时，先使用游戏自带的暂停键。

程序将识别已有加载器或配置冲突并提示处理。先选择适合该游戏的扩展方式。图形接口或加载条件无法确认时，可以先用桌面检索。

## 3. 接入 Electron 游戏

选择包含实际游戏 EXE 与 `resources/app.asar` 的目录。先点「接入双语语料」，再在「面板设置」点「保存并启用」。**从工作台启动**，按 F8 打开，确认当前页面里的原位双语和检索。大、小面板切换时会保留搜索和选词，长文可按窗口宽度并栏或上下显示。

通用语言接入需要有稳定键的中英文资源和可识别的本地页面，复杂页面需要专用适配。游戏更新后重新接入。

## 4. 只有文本也可以先建词句库

在「资料 → 导入文本」选单文件，导入 UTF-8 JSON / CSV / TSV，至少提供 `key`（或 `id`）、`en`、`zh`。可另带 `namespace`、`category`、`speaker`、`source`、`note`、`phrases`。成对模式可导入稳定键 JSON 或已提取的 locres。桌面检索热键是 **Ctrl+Shift+B**，窗口化或无边框更方便返回游戏。

## 5. 游玩时查一条，退出后复习

- 游戏内面板可用时，按 **F8** 打开，在原句里选择表达并收藏，按 **Esc** 回游戏。不要为了学习而让面板一直盖住游戏。
- **Ctrl+Shift+B** 是 Windows 桌面检索的主动备用入口，F8 安装后未加载也可以用。窗口化或无边框模式更方便切回。工作台点击「收藏整句」，或查找当前英文原句中的词语后点击「收藏词语」，不弹出复习窗口。若按 Esc 没能切回游戏，工作台会留着提示；可用 Alt+Tab 手动切换，或再按一次 Esc 只收起窗口。
- 游玩结束再打开「收藏与复习」→「开始回想」。先看英文，想到大意后显示译文、释义和个人备注；切到下一条时答案重新隐藏。普通收藏浏览不受影响；词句、释义与备注依然使用同一个本地笔记库。

## 更新、移除和备份

- 关闭游戏后，用「游戏 → 移除游戏内检索面板」移除面板。恢复原版文本用独立入口「游戏 → 恢复原版显示」。
- 移动工作台或更新游戏之前，留好游戏目录的 `.bilingual-workbench`、工作台 `data` 和游戏原有存档。重接入后在新版本测试一句显示与一次 F8 操作。移动工作台时，重新生成双语快捷方式并确认面板数据库路径。
- 收藏与备注在工作台 `data/notes.sqlite3`，备份它可保留复习资料。故障记录在 `logs/workbench.log`。报告问题时，可以附上游戏版本、引擎、当前窗口模式、复现步骤和已去除私有路径的错误片段。
